## Notes

SideB Candidate is an experimental KNULLI package for device validation. It is
not a supported release until real-device proof confirms launch, framebuffer
display, input, Spotify Connect visibility, local playback, and clean exit.

## Install

Extract the archive into the KNULLI `roms/ports` folder so the `sideb/`
directory is visible to EmulationStation or PortMaster.

## Controls

| Button | Action |
|--|--|
| A | Play / Pause |
| Left / Right | Previous / Next track |
| Up / Down | Volume up / down |
| X | Favorite or remove confirmation |
| Y | Open / close FAV LIST |
| B / MENU | Exit app |
